How to organize a Magic: The Gathering binder

Every collection starts as a shoebox. The moment you want to find a card, trade one, or build a deck from what you own, the shoebox stops working, and a binder is the usual next step. The hard part is not buying the binder. It is deciding what goes on which page, and then keeping that decision true after the next prerelease, the next bulk lot, and the next time a deck gets taken apart.

With SpellControl you scan or import your collection, and it files itself into your binders by the rules you set. The rest of this guide covers the physical side of the job.

This guide covers the physical basics, the three sorting schemes that hold up over time, and the approach SpellControl takes: describe each binder as a set of rules, and let every card file itself.

Pocket math first

A standard binder page has nine pockets. Two facing pages make an eighteen-card spread, which is the unit you actually look at when the binder is open. Some collectors use four-pocket pages for oversized or premium cards, and twelve-pocket pages exist for side-loading binders. Whatever you use, count in pages, not cards: a 591-card binder is 66 nine-pocket pages, which is a full two-inch binder with no room to grow.

  • Leave empty pockets at the end of each section. A section with no slack means every new card forces a reshuffle of everything behind it.
  • Side-loading pages keep cards from sliding out when the binder is stored upright.
  • Keep the sort order printed or written inside the front cover. The order you chose is obvious today and a mystery in six months.

The three sorting schemes that hold up

Most binders end up using one of these, and each answers a different question.

By color, then name

The classic trade binder. White, blue, black, red, green, multicolor, colorless, lands, with cards alphabetical inside each color. It answers "do you have a copy of X" in a few seconds and needs no memory of sets. Its weakness is that it says nothing about what a card does.

By set, then collector number

The completionist's binder. It mirrors the printed set list, so gaps are visible at a glance and set booklets line up with the pages. It falls apart the moment you own more than a few sets, because the same card from three printings lives in three places.

By role

The deck builder's binder: ramp in one section, removal in another, card draw, counters, commanders, lands. It answers "what could this deck use" without opening a search engine. It is also the hardest to maintain by hand, because a card's role is a judgment call and every new card needs one.

Why binders drift

Every scheme works on the day you build it. They break for the same reason: new cards arrive faster than you re-sort. A prerelease adds forty cards that need a home. A deck comes apart and returns a hundred. Bulk from a friend adds three hundred. Each time, the honest options are to spend an evening re-filing or to start a "to sort" pile that quietly becomes the shoebox again.

Rule-based binders

SpellControl replaces the by-hand decision with a rule. Each binder is defined by what it should contain: a color identity, a type line, a set, a price range, a rarity, an oracle tag like Mana rock or Removal, a mana value range, or any combination. Cards file into the first binder whose rules match, top to bottom, and everything that matches nothing lands in an Uncategorized bucket that tells you exactly which rule to write next.

Because the rules are the binder, re-sorting is free. Import a prerelease haul and the forty cards are already on their pages. Take a deck apart and the cards return to the binders they came from. Reorder the binder list and every card re-files in the new priority. Each binder has its own pocket size and sort order, and the page view shows the physical layout, page by page, so what you see on screen is what you flip through at the table.

A setup that works for a lot of Commander players:

  1. Commanders: commander-eligible cards, sorted by color then name.
  2. Removal and counters: the oracle tags for removal, board wipes, and counterspells, sorted by color then mana value.
  3. Mana rocks and ramp: the ramp tags, sorted by mana value.
  4. Lands: the type line contains Land, sorted by name.
  5. Everything else: no rules, so it catches what the first four did not.

Cards reserved by a deck are tagged on the binder page, so a pocket that reads "in Atraxa" does not get traded away by accident. Every binder exports to a plain list for printing or sharing.
